## Summative Lab: JavaScript Calculator

** Introduction **

This project focuses on creating a simple yet efficient JavaScript Calculator. The final goal is to use four different arithmetic functions to calculate simple equations, and store the results in an array to be called on later.


** Technologies **

Javascript ES2024


** Features **


A function to push each calculation to the array and store them as objects.
Four different functions to perform basic arithmetic: addition, subtract, multiplication, and division.
A function to display calculation history, which is stored in the array.
